Music Man Application

React application for musicians to practice with recorded audio

Application Status

The Music Man React application has been built with the following components:

  • Audio Import: Import audio files for practice
  • Section Looping: Set loop start/end points
  • Tempo Control: Adjust playback speed (50% - 150%)
  • Metronome: Adjustable BPM metronome (40-240 BPM)
  • Count-In: Configurable count-in before playback
  • Save/Modify Songs: localStorage persistence
  • Setlists: Create and organize song sets
  • Song Transitions: Navigate through setlists
  • Sharing: Export song configuration as JSON

How to Run Locally

Due to a Vite build issue in this environment, please run the application locally:

cd C:\Users\tlparks\MINSCLASS
npm install
npm run dev

Then open http://localhost:5173 in your browser.
